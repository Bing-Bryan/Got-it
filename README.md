# Got it

**Make sense of it. Keep reading.**

遇到不懂的地方，原地弄明白，继续读。

**简体中文** · [English](README.en.md)

## 为什么做 Got it

AI 可以很快生成一份长报告，但读懂它仍然需要时间。

读商业分析、调研报告或长文章时，我们可能遇到一个陌生概念、一段难懂的论述，或一项不确定依据的数据。为了弄清楚，我们会复制原文，打开一个 AI 应用，补充背景，再请它解释。

问题可能解决了，但解释散落在不同的对话里，与原文失去了联系。回到文章时，还得找回刚才的阅读思路；下次再读，又未必记得当时问过什么、答案在哪里。

Got it 希望把这个过程留在文章旁边：**选中不懂的内容，获得解释或查证，弄明白后继续读。** 值得保留的理解可以沉淀为与原文关联的知识卡片，之后再回来查看。

## 当前 MVP 能做什么

Got it 是一个围绕 Markdown 文章展开的 AI 阅读工具。

| 当你遇到…… | Got it 可以帮你…… |
| --- | --- |
| 不熟悉的概念或术语 | 结合原文上下文解释含义，提供简单例子。 |
| 不认识的公司、产品或事物 | 介绍它是什么、做什么，以及它与文章的关系。 |
| 不确定依据的数据或论述 | 查找相关来源，呈现证据与原句的关系，以及仍然存在的缺口。 |
| 仍然不容易理解的解释 | 选择“再简短一点”或“举个简单例子”。 |
| 想留住的理解 | 沉淀知识卡片，保留原文关联，并导出为 Markdown。 |

联网查证需要使用支持搜索的 AI 连接。没有充分证据时，Got it 会保留不确定性，不把 AI 的回答当作已经证实的事实。

## 一次阅读，怎样使用

1. **打开文章。** 导入一份 Markdown 文档，开始阅读。
2. **选中卡住你的内容。** 选择“解释概念”“介绍一下”或“查证信息”。
3. **在原文旁弄明白。** 查看回答，按需简化、看例子或检查来源。
4. **回到正文。** 点击“明白了，继续阅读”；值得留下的内容可以沉淀为知识卡片。

知识贴与原文位置关联，保存在当前浏览器本地，之后可以重新打开查看。当前版本支持独立导出知识卡片，不会改写原 Markdown 文件。
