## 真实阅读流程

使用用户指定的陪伴类 AI 产品分析报告（约 14k 字符、24 个目录项），从实际浏览器文件输入导入隔离阅读库。未修改原报告，不分发全文。选择通过浏览器 DOM Range 建立真实原文选区，再点击应用功能按钮；没有注入模型回答。

| 场景 | 实际观察 |
| --- | --- |
| 导入与保存 | 正文、目录、表格可阅读；显示已保存到本机；浏览器导入明确显示未关联原文件 |
| CAGR 解释 | GPT-6 Luna，约 9.15 秒完成，首字约 4.71 秒；解释复合增长与预测局限，0 来源 |
| 18–34岁查找 | GPT-6 Astra，约 90.79 秒完成；3 次成功搜索、2 来源；证据结论 partial，未升级为完全支持 |
| 引用核对 | Appfigures 介绍页的一段声明被逐字核对；PDF 来源不冒充已完成正文核对。被核对的声明本身不能证明年龄主张 |
| 打开来源 | 点击真实来源链接，新页打开 Appfigures 对应报告介绍页，标题和 URL 对应 |
| MiniMax 介绍 | GPT-6 Luna，首轮约 21.21 秒；1 次搜索、1 个官网来源；未知信息明确保留 |
| 学习确认 | CAGR 与查找条目确认完成；证据结论仍为 partial |
| 取消真实请求 | 点击详细介绍后停止，显示本轮未完成；历史完整回答仍可展开。此次立即取消，未验证收到长正文后的人工取消 |
| 取消后重试 | 点击重新生成，真实返回更详细的 MiniMax 介绍与来源；旧答案仍在历史中 |
| 首次登录取消/重试 | 全新隔离 Codex 配置显示未登录；从应用发起授权，因官方页面连接关闭而取消，界面显示已取消；重新发起成功进入等待，未冒充已连接 |
| 服务重启 | 关闭实际服务并离开页面，再启动与打开；三个知识贴、ID、消息数量及已理解状态保持，中断状态正确恢复，没有新增回答 |
| 窄屏 | 390×844，知识贴面板与关闭按钮可见，页面宽度为390，无整页水平溢出；只做受影响关键界面检查 |

上表耗时来自本次服务端安全计时字段，不是点击端到端性能承诺。页面重开观察窗口未捕获到运行时异常事件；不等于整个会话所有浏览器扩展和控制台都没有错误。

- 使用全新的隔离 Codex 配置目录，之前明确显示未登录；没有注销或替换原有 Codex 登录。
- 登录状态为 `succeeded`，Provider 为 `connected`；应用自动显示“本机 Codex CLI 已连接”。
- 模型接口返回 7 个可用模型；数量为本账号本次结果，不保证其他账号相同。
- 在实际 UI 选中内置示例中的 CAGR，点击解释概念，真实返回完整解释和继续阅读按钮。不是只验证授权回调。

## GitHub 首次上传与跨平台修复

代码已上传到 [Bing-Bryan/Got-it](https://github.com/Bing-Bryan/Got-it)。保留既有中英文介绍的远程历史，没有上传原开发仓库历史或旧验收材料；同步修正英文介绍的旧保存/导出说明。

[首次 CI](https://github.com/Bing-Bryan/Got-it/actions/runs/36262413088) 中 macOS/Linux 全部通过，Windows 暴露目录 `fsync` 的 EPERM 及两处 Unix 专用测试夹具问题。已修复：Windows 保留普通文件写入、文件 fsync 与原子改名，不执行不支持的目录 fsync；POSIX 目录 fsync 继续保留，其他错误不吞掉。流式测试改用真实 Node 子进程执行跨平台夹具，桌面运行路径测试按宿主路径规则生成预期。不跳过 Windows 测试。

真实突然断电的恢复效果仍未验收；Windows 不具备本实现的 POSIX 目录元数据同步步骤。三平台最新自动检查以仓库 [Actions](https://github.com/Bing-Bryan/Got-it/actions) 为准；测试通过不等于各平台原生文件选择器与浏览器交互都已实机验收。

本地发布副本建立后，发现测试默认递归扫描 release 目录；现将测试入口限定为 src 与 server，避免重复运行旧快照。键盘焦点测试明确等待初始阅读位置恢复完成后再观察焦点动作，并等待下一帧检查，消除初始化滚动被误算为键盘滚动的时序误判。
