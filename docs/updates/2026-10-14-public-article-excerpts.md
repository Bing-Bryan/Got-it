# 2026-10-14：保存付费文章的公开部分

链接导入现在可保存具有可靠公开正文和明确可见付费边界的静态文章，公开范围不再依赖单篇 URL 许可。阅读器持续标明“仅保存公开部分”，保存与重开后保留同一范围。

登录要求、挑战、公开正文不足或边界不明仍会明确失败，不读取隐藏内容或付费门槛后的文字／媒体。必要媒体失败仍阻止一键导入。正常正文中讨论付费墙、引用相关文案或普通订阅推广不会据此标为节选。

本轮在隔离库验证新 Lenny 文章导入、保存及重开，9 张图片全部保存；另以受控全付费页面验证失败不入库。未增加模型请求，也没有修改阅读器布局。截图工具不可用，未新增截图；现有 README 图片仍用于介绍界面，不作为本次验收证据。静态提取仍不保证支持任意网站。

## Save the public portion of paywalled articles

URL import can now save static articles with reliable public text and a clear visible paywall boundary, instead of granting excerpt permission to one exact URL. A persistent notice discloses the saved public scope, including after reopening.

Login requirements, challenges, insufficient public text, or unclear boundaries still fail. Hidden and post-paywall text and media are not read, and required missing media still block one-click import. Editorial discussion, quoted paywall copy, and ordinary subscription promotions do not by themselves mark an article as an excerpt.

The new Lenny article was imported and reopened in an isolated library with all nine images saved. A controlled all-paid page failed without creating an entry. This update adds no model requests or reader-layout changes. Screenshot tools were unavailable, so no new screenshots are claimed; existing README images introduce the interface and are not evidence for this update. Static extraction still cannot support every website.
