# 翻译进度、继续翻译与格式恢复

本轮让翻译状态更容易理解：计数标明已翻译的文本块，悬停或键盘聚焦可查看单位说明；等待时间从点击开始累计，跨批不归零。未完成的文章直接显示「继续翻译」，保留已有成果，只请求缺失部分。停止与超时分别提示，保存失败可重试保存。

网页翻译专用 GPT-6 Luna / medium，解释、查证等知识贴的设置不受影响。提示要求根据语境使用自然中文，同时保留限定、并列内容、因果与术语含义；这不是语义质量保证。已有译文不自动重译，新旧模型成果可并存并保留来源记录。指定模型不可用时明确失败，不静默替换。

若模型遗漏原格式标记，仅失败的文本块在本批原有时间预算内补译一次；其它有效块不重复生成，仍严格校验结果。成功时显示本轮修复块数，继续失败保留先前成果。网络、超时和其它可检测质量错误不触发这次补译，用户错误提示不展示内部诊断。

添加材料入口改为独立「+」按钮，悬停展开、移出按钮和菜单区域收起，保留点击与键盘操作；菜单标明 MD / PDF 与静态文章 / X。同时兼容实际 X 文章响应中的合法链接元数据，保留文章身份与正文结构检查。

中英文 README 的八张图片重新从当前应用拍摄，使用隔离安全示例；PDF 为自制合成图表。画面中的历史 AI 回答来自此前保存的真实结果，本轮截图没有请求新回答。实际验证与限制见[发布结果](../release-results.md)，平台结果以本次 GitHub Actions 为准。
