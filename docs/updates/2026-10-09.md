# 阅读辅助与版本选择更新

2026-10-09 发布整理；功能与冒烟验证于 2026-10-08 完成。继续作为 v0.1.0 早期试用版，不承诺稳定版或跨平台原生交互全覆盖。

## 本次变化

- 解释概念与介绍合并为「解释一下」，与「查找来源」并列；「问一问」直接展开文本框，支持具体问题及后续追问。
- 同一处原文可以保留解释、来源与多个问题。首次优先打开已有解释，之后记住查看的结果；「我的问题」切换入口只显示标题。
- 返回箭头、返回文字和原文摘录同行。返回列表恢复位置，点击摘录定位原文；窄屏定位成功后收起回答面板。移除理解确认、独立 PDF 预览及 OCR 纠正按钮，保留旧数据和原图。
- 提问框点击空白一次关闭。版本差异用自然语言说明，只对不同且未处理的记录要求选择；关闭后本次阅读不连续弹出已有的其他待处理记录，重开可继续处理。
- 全部用途默认 GPT-6.1 SOL / Medium。修复新版内置 Codex 程序发现，模型目录支持刷新；目标型号不可用时明确提示，不静默换型号。
- 此前已完成但上个公开快照尚未包含的 PDF 自动目录一并同步：本机生成并保存，成功不常驻编辑/保存按钮，失败可重试。

## 验证与边界

10 月 8 日：55 个测试文件、402 项测试、类型检查与构建通过；Chromium 桌面与 390×844 窄屏走查阅读、提问、切换、停止/失败/重试、PDF 定位及版本选择。浏览器使用隔离受控数据；两次真实 Codex 调用确认 GPT-6.1 SOL / Medium 可用于计算问答与来源搜索。

真实搜索样本的引用读取不受支持，最终是部分支持，没有把搜到链接当作已核实。没有重新执行真实 OCR、真实断电或磁盘写满；Windows/Linux 原生 UI、移动真机未验证。PDF 仍仅在本机保存与重开，不新增 PDF 阅读文档或 JSON 导出。

公开包只包含代码、公开说明和已审核展示图片，不包含个人阅读库、完整报告、内部验收材料或开发 Git 历史。原文不会因更新被改写。
