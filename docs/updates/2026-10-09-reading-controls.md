# 阅读调节、提问与响应式侧栏

2026-10-09。继续作为 v0.1.0 本地早期试用版。

## 本轮变化
- 左右侧栏独立固定和收起，阅读区使用释放的空间。右栏支持 220–720px 调宽，完整标签／图标加数量／仅图标逐级适配；最小宽度后继续拖动并松手可收起，展开保留宽度和草稿。
- PDF 页面缩放与 Markdown 正文宽度统一为正文右上角图标浮层；两种格式的保存状态统一靠右，连续保存不反复闪字。Markdown 代码块采用浅色底及正文字号。
- 文档页头显示本机估算的阅读时间。PDF 仅使用足够完整的原生文字，不为估算运行 OCR 或调用模型。
- 解释及查找来源采用“还是不懂？＋问一问”，移除再解释下、再找一下和查证历史入口；旧记录保留，失败可重试。Enter 发送，Shift+Enter 换行，输入法候选确认不误发。
- 右侧我的问题列表下方新增“向全文提问”。短文使用完整文字，长文最多发送 16000 字符的结构与相关材料；PDF 无充分原生文字时明确未完成，不自动 OCR。
- 普通问题优先简短回答及紧凑参考链接；来源核对结果保留完整来源卡。品牌头部仅显示 Got it。

## 验证范围
本轮归档重新执行 66 个测试文件／474 项测试、类型检查、构建与发布启动检查，全部通过。实施期间使用隔离合成材料检查桌面／窄屏、Markdown／PDF 调节及切换、提问、停止与失败、侧栏收起恢复和草稿。归档检查未重新调用真实模型、OCR 或修改用户阅读库；不将历史模型样本视作本轮真实搜索验收。远程三平台结果以 [GitHub Actions](https://github.com/Bing-Bryan/Got-it/actions) 为准。

公开更新沿用白名单快照与独立仓库历史，不含个人阅读库、内部 OpenSpec、验收截图和开发历史；未部署公网服务或创建 GitHub Release。原文件不被改写。
