# 2026-09-30 · PDF 图文阅读与知识贴整理

Got-it 现在支持 Markdown 与 PDF 在同一个本机阅读列表中保存和重开。本次更新包含此前公开版之后的阅读与提示词改进。

## 新增与调整

- PDF 原页连续上下滚动，自动适合阅读区宽度，保留图表与版面。
- 可用原生文字直接拖选；图片或不可选正文使用「框选内容」，直接选择解释概念、查找来源或介绍一下。选择功能后才在本机识别，模型收到局部图像和有限辅助文字。
- 识别文字可在知识贴查看和纠正；保存重开可返回同一页、同一区域。
- 左侧导航可收起、悬停展开或固定；展开时阅读区同步适配。
- 选区浮窗紧贴原文。页码、框选、行内说明和真实保存状态合并为36px工具栏。
- 首次解释及「再解释下」按需搜索，不再单列联网补充按钮。历史模式和失败重试保留，搜索、引用核对和事实支持仍是不同状态。
- 分类标题垃圾桶开启删除模式；每条右侧同轴图标首次点击变确认，再点击才删除。删除取消该条正在执行的请求，保留其他知识贴及原文。

## 验证与限制

交付实现已在 macOS 通过310项自动测试、类型检查和生产构建。桌面与390px窄屏验证了阅读、两步删除、键盘退出、保存重开及受控保存失败重试；请求取消与迟到事件使用受控测试。PDF阶段另已使用真实模型验证文字、图表与图文请求及保存回跳，本次归档不重复调用模型。跨平台自动检查以本次提交的 GitHub Actions 结果为准，不沿用旧版成功结论。

- PDF 上限50 MiB、200页，不支持加密文件。首轮 OCR 覆盖简体中文和英文，需要读者核对。
- 无整页自动分栏识别；复杂页先限定区域。Markdown 的本地相对图片导入仍待解决。
- PDF不是可独立携带的 `.focus`/JSON 导出；应在服务关闭后备份完整应用数据目录。
- 删除当前知识贴不代表擦除历史版本或共享资源文件。
- Windows/Linux 的原生交互与文件选择器尚无实机验收。无账号、云同步或公网部署。

## English summary

This update adds continuous, width-fitted PDF reading, native text selection and region-based local OCR, image-aware assistance, persistent page anchors, a collapsible sidebar, compact reading controls, on-demand explanation search, and two-click card deletion. Original documents remain unchanged. The implementation passed 310 local tests; current cross-platform checks are reported by GitHub Actions. Native Windows/Linux UI validation, full-page column recognition, and Markdown relative-image import remain outside the verified scope.
